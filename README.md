## Project Description

This project is a Python application that connects to a Redis database and allows users to perform CRUD operations using a menu-driven interface.

## Python File

RedisCRUD.py - A Python program that allows users to create, retrieve, update, and delete Redis sets and their members.

## Features

- Create new Redis sets
- Retrieve members of existing sets
- Add and remove members from sets
- Delete individual sets
- Delete all data from the Redis database
- Display system date and time
- Exit the application

## Technologies Used

- Python 3
- Redis
- redis-py
- Ubuntu Linux
- Visual Studio Code
